# 디자인 가이드 — Hobby Atlas (hobbyDB v2 재설계 · 수집 도감 앱)

> 기획 5단계 "화면 기획"(발표자료 부록 B5 화면별 요소 분석표)의 요약본입니다. **코드의 화면 파일 맨 위 대응표와 번호 · 명칭이 같아야** 합니다(UI 25점 "기획과 일치").
> 3장 요소표는 각 화면 파일 맨 위 대응표에서 그대로 옮겼습니다. 화면을 바꾸면 코드 대응표 → 이 문서 → 원칙 카드 순서로 같이 고칩니다. 이 가이드에 없는 화면은 만들지 않습니다(감점).
>
> 2장 "현행 앱 근거"는 App Store 리뷰(2026-10-26 확인)를 한국어로 요약한 것 — 전체 표 · 별점 분포 · 유형 분류는 `docs/기획.md` 1장. 4장 각 규칙의 "의도"는 셀프 논증(`docs/셀프논증.md`)과 함께 확정합니다.

  탭 **안에서** 바뀌는 보기(O 전체 목록 · G 도감 · 검색 판)는 새 화면이 아니라 그 화면의 `setState` 표시 변화입니다.
- **적응형** (창 너비 · 높이 기준, `MediaQuery.sizeOf` · `LayoutBuilder`, 기기 종류 · 방향 고정 없음):

  - 가로로 눕힌 폰(너비 > 높이 · 높이 < 520): 측면 탭(S-5) — 아바타 / 탭 4개 / 🔔 ⚙, 높이가 모자라면 측면 탭만 스크롤
  - 폴드 펼침 · 태블릿 · 넓은 창(너비 ≥ 700): **반반 화면**(S-12) — 왼쪽 = 폰 화면 그대로, 오른쪽 = 자세히 칸. 폴드 접힘선(`displayFeatures`)이 있으면 거기서, 없으면 왼쪽 45%(320–460)
  - D 상품 상세: 칸 너비 ≥ 720이면 사진 왼쪽 · 정보 오른쪽(D-13). H 캘린더: ≥ 720이면 달력 왼쪽 · 목록 오른쪽(H-7)
  - 격자(O · G · 게시물): 칸 너비로 열 수 계산. A 배너 높이 ≤ 화면 높이의 절반
  - 확인: `test/layout_test.dart` — 320×568 · 390×844 · 844×390 · 690×830 · 830×690 · 768×1024 · 1280×800 에서 주요 화면 넘침 0 (`flutter test`)

## 4. 디자인 가이드 글 — 모든 화면이 따르는 규칙

### 색의 뜻 (S-15 · `lib/theme.dart`)
- **목적**: 색만 보고도 "고를 수 있는 것"과 "이미 가진 것"을 구분하게 한다.
- **내용**: 바탕은 흑백(검정 #111 · 회색 · 흰색). 포인트는 두 가지뿐: **파랑**(Gp.accent) = 고름 · 누를 수 있음 · 좋아요 · 안 읽음, **민트**(Gp.own) = 가진 것(구매함 리본 ✓ · 구매함 칸 테두리 · 인증 배지 · 수집 막대). 빨강은 삭제 · 로그아웃에만. 상품 사진 외의 큰 검정 바탕 + 흰 글자 면은 쓰지 않는다.
- **의도**: P04 · P08 — 셀프 논증 후 확정

### 모양의 뜻 — ♡ · 리본 · 배지 (A-9 · D-6 · G-4b · O-4)
- **목적**: 같은 행동은 어느 화면에서나 같은 모양으로 누른다.
- **내용**: ♡ = 좋아요(갖고 싶다), 책갈피 리본 + → ✓ = 구매함(가졌다), 🏅 배지 · 도는 색 고리 = 내 사진으로 인증. 상품 사진 위에서는 왼쪽 위 리본 · 왼쪽 아래 ♡ (MarkOverlay 하나), 버튼일 때는 같은 아이콘의 TogglePill. 컬렉션 탭 아이콘은 리본과 겹치지 않게 모자이크 격자.
- **의도**: P04 · P06 — 셀프 논증 후 확정

### 도감 4단계와 레벨 (G-4 · G-4a)
- **목적**: 하나 더 모을 때마다 "올라간다"는 느낌을 준다.
- **내용**: 칸: 흑백(없음) → 컬러(♡ 좋아요) → 컬러 + 초록 테두리(리본 구매함) → 내 사진 + 도는 고리 + 배지(사진 인증). 1 · 2 · 3점, 5점마다 작품 Lv 상승(막대 애니메이션 · 토스트). 읽는 법은 긴 범례 대신 ? 버튼(G-2).
- **의도**: P01 · P10 — 셀프 논증 후 확정

### 글자 6단계 (S-15)
- **목적**: 크기만 보고 정보의 높낮이를 알게 한다.
- **내용**: Gp.t11(배지 · 시간) · t12 = 12.5(보조 글) · t14(본문 · 버튼) · t16(시트 제목) · t19(화면 · 섹션 제목 · 상품명) · t24(가격 · 큰 숫자). 이 밖의 크기는 쓰지 않는다(코드에 숫자로 쓴 글자 크기 0개).
- **의도**: P08 · P04 — 셀프 논증 후 확정

### 면과 층 (A-8)
- **목적**: 줄과 줄 사이 경계를 선 없이 보이게 한다.
- **내용**: 회백색 바탕(#F7F7F5) 위에 흰 띠(SectionPanel)를 10dp 틈으로 쌓는다. 제목 앞에는 파랑 막대(SectionHeader). 떠 있는 흰 버튼(Gp.raised)은 아바타 · 카메라 · 채널 타일에만.
- **의도**: P08 — 셀프 논증 후 확정

### 접근성
- **목적**: 작은 화면 · 큰 손가락 · 낮은 시력에서도 쓸 수 있게 한다.
- **내용**: 보조 글자 #767676 이상(흰 바탕 대비 4.5:1, WCAG AA). 사진 위 ♡ · 리본 누르는 자리 44dp, 작은 × 40dp. 좁은 화면에서 글자는 말줄임 · 줄바꿈 · 축소(넘침 0을 테스트로 확인).
- **의도**: P08 · P09 — 셀프 논증 후 확정

### 되돌리기와 확인 (F-7 · F-10 · D-12 · K-5)
- **목적**: 실수해도 바로 되돌릴 수 있게, 되돌릴 수 없는 일은 한 번 묻는다.
- **내용**: 켜고 끄는 일(좋아요 · 구매함 · 점등 · 읽음 · 알림 지우기)은 바로 하고 토스트에 "되돌리기". 여러 개 삭제 · 제보 · 로그아웃 · 기록 지우기는 먼저 확인 대화상자. 지운 상품은 휴지통에서 다시 켬.
- **의도**: P03 · P05 — 셀프 논증 후 확정

### 표기 (D-5 · O-4)
- **목적**: 같은 정보는 같은 모양으로 쓴다.
- **내용**: 날짜는 어디서나 2027.09 · 2026.10.16 (dateDot). 엔화 = 일본 정가(상세 가격 위 "일본 정가"), 원화 = 국내 시세 · 내 구매가. 건담 작품명은 영어(The Witch from Mercury · Hathaway …), 한글 줄임말은 검색어로만 남김.
- **의도**: P02 · P04 — 셀프 논증 후 확정

### 한 벌로 이어지는 상태 (S-16)
- **목적**: 한 곳에서 바꾼 것이 다른 화면에서도 같게 보이게 한다.
- **내용**: 좋아요 · 구매함은 맨 위 MarksHost 하나(setState 를 위로 올림): 홈 카드에서 ♡ → 컬렉션 목록 · 상세 버튼 · 내 정보 숫자 · 친구 컬렉션 "나도 있음"이 같이 바뀐다. 반반 화면의 "오른쪽에 연 것"도 PaneHost 하나 → 왼쪽 카드 테두리 · 줄 바탕.
- **의도**: P04 · P01 — 셀프 논증 후 확정

### 가짜 기능은 가짜라고 (AGENTS.md)
- **목적**: 실제 동작 없이도 흐름을 끝까지 보여 준다.
- **내용**: AI 검색 후보 · 카메라 인식 · 사진 인증 판정은 미리 쓴 결과. 백업 · 복원 · 로그아웃 · 공식 링크 · 친구 요청 · 사진 저장 · 알림 받기 · 제보는 토스트로만 응답(저장 · 전송 없음). 문구는 앱처럼 자연스럽게 쓰고, "가짜"라는 사실은 이 문서와 발표에서 밝힌다.
- **의도**: P10 — 셀프 논증 후 확정

## 5. 상태관리 포인트

화면 안 표시 변화는 그 화면의 `setState`로만 바꿉니다. 여러 화면에 걸친 값(좋아요 · 구매함 · 오른쪽 칸에 연 것)은 **맨 위 StatefulWidget 의 setState + InheritedWidget** 으로 내려 줍니다(상태관리 패키지 없음). 영구 저장은 하지 않아 앱을 끄면 db.json 의 처음 값으로 돌아갑니다.

## 6. 규칙(AGENTS.md) 점검

| 규칙 | 지키는 방법 |
|---|---|
| 전환 3방식 | 쌓기(CupertinoPageRoute) · 옆으로(탭 + IndexedStack, 밑줄 탭) · 덮기(bottom sheet · dialog · Drawer · 필터 패널 showGeneralDialog). 반반 화면 오른쪽 칸도 칸 안 Navigator 의 push/pop |
| GET 만 | 요청은 `lib/api.dart` 의 `_get` 하나(json-server). post/put/patch/delete 없음 |
| setState 만 | 화면 안 = 그 화면 setState, 여러 화면 = 맨 위 setState + InheritedWidget(MarksHost · PaneHost). ValueNotifier/ChangeNotifier 0개 |
| 3상태 | GET 하는 화면 모두 LoadingView · ErrorView · EmptyView (`--dart-define=DEMO_STATE=loading/error/empty` 로 시연) |
| 창 너비 적응형 | 1장 "적응형" — 기기 종류 · 방향 고정 없음, 7가지 크기 테스트 |
| 패키지 | `http` 하나 (pubspec 그대로) |
| 실제 동작 없음 | 로그인 · 결제 · 저장 · LLM 호출 없음, 4장 "가짜 기능은 가짜라고" |
| 자가 점검 grep | `grep -rnE "http\.(post|put|patch|delete)|SharedPreferences|sqflite|hive|FirebaseAuth|ChangeNotifierProvider|Riverpod|BlocProvider" lib/ pubspec.yaml` → 결과 없음 ✅ |

## 7. 알려진 한계 · 다음 단계 (발표에서 먼저 말할 것)

- **저장 없음**: 좋아요 · 구매함 · 점등 · 게시물 공개 범위 · 읽음 등은 앱을 끄면 처음 값으로 돌아간다(규칙: 영구 저장 금지).
- **도감 칸 상태**는 그 작품 도감 화면 안에서만 유지된다 — 기체(도감 칸)와 상품은 다른 단위라 앱 전체 한 벌(MarksHost)에 넣지 않았다.
- **게시물 공개 범위 · 숨긴 사진**은 내 정보 화면 안에서만 유지된다.
- **폴드를 접으면** 오른쪽 칸에 열려 있던 화면은 닫힌다(왼쪽 탭 상태는 유지).
- **🔔 의 점**은 늘 보인다(안 읽은 알림 수를 셸에서 다시 GET 하지 않음). 설정의 "내 채널 소식만" 스위치는 표시만 바뀐다.
- **로고 미정**: 앱 이름은 Hobby Atlas 로 확정했지만 앱 아이콘은 아직 기본 아이콘.
