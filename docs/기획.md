## 4. 피쉬본 — "수집가가 현행 앱에서 컬렉션 관리를 그만둔다"

| 시각 | 원인 |
|---|---|
| 모바일 UX | 웹 메뉴(Database · Subjects · Market …)를 앱에 그대로 · 기능마다 새 창 · 폰 화면에 잘 안 맞음 |
| 사용성 | 쇼케이스 · 컬렉션 · 위시의 차이가 안 보임 · 상태가 모양으로 구분되지 않음 · 익히기 어려움 |
| 데이터 | 일반판 누락 · 사용자가 추가 · 오류 표시를 못 함 · 시세 출처 불명 |
| API | 시세 조회 횟수 제한(유료 유도) · 스캔 → 검색 연결이 멈춤 |
| 네트워크 | 스캐너 멈춤 · 원치 않는 새로고침 · 처음 화면으로 튕김 |
| 프로세스 | 광고가 화면마다 · 구독 정책 변경 · 오래된 사이트(PPG)를 흡수하며 구조가 복잡해짐 |

## 5. 5 Why — 우선순위 1: "인터페이스를 익히기 어렵다" (2023-11-23 · 2023-04-18)

1. **왜 익히기 어렵나?** → 같은 일을 하려 해도 메뉴가 많고, 누를 때마다 다른 창이 열린다.
2. **왜 메뉴가 많고 창이 열리나?** → 웹사이트의 정보 구조(데이터베이스 · 주제 · 마켓 · 회원 · 블로그)를 그대로 앱 화면에 넣었다.
3. **왜 웹 구조를 그대로 썼나?** → 앱이 "데이터베이스를 보여 주는 창"으로 설계되어, 수집가가 하는 일(소식 → 찾기 → 판단 → 기록 → 보기)이 아니라 데이터 종류로 화면을 나눴다.
4. **왜 데이터 종류로 나눴나?** → 여러 수집 분야(펀코 · 다이캐스트 · 피규어 …)를 하나의 메뉴로 모두 덮으려 했기 때문에, 사람마다 관심 분야가 다르다는 점이 화면에 없다.
5. **근본 원인** → **"내 관심 분야(채널)"와 "내가 하는 일의 순서"가 화면 구조의 기준이 아니다.**

→ v2 해결: 위에는 **내 채널 바**(C) 하나, 아래에는 일의 순서대로 **홈(소식) · 검색(찾기) · 카메라 · 캘린더(발매) · 컬렉션(기록 · 도감)** 탭. 한 화면 안에서 끝나는 일은 시트(덮기)로, 새 창 대신 같은 탭 안 보기(O 전체 목록)로.
